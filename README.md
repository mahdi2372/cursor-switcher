# Cursor Switcher - 280 Premium Packs

Ultra sexy Windows cursor switcher with **280 premium cursor packs** and auto-download.

## Features

- **280 cursor packs** - anime, neon, gaming, macOS, Windows 11, cute, material, and more
- **Ultra sexy ASCII UI** - gradient logo, Unicode box borders, clean layout
- **Auto-download** - first run downloads all packs from GitHub automatically
- **One-click apply** - type pack number, cursor changes instantly
- **Windows Default restore** - press D to reset anytime
- **Pagination** - 15 packs per page, N/P to navigate

## Quick Start

1. Download `Cursor Switcher.bat` from [latest release](https://github.com/mahdi2372/cursor-switcher/releases/latest)
2. Double-click to run
3. First time: packs auto-download (13 MB)
4. Type a number to apply, `N`/`P` to page, `D` for default, `0` to exit

## Manual Install

1. Download `cursor-switcher-v2.zip` from [releases](https://github.com/mahdi2372/cursor-switcher/releases/tag/v2.0)
2. Extract to `%LOCALAPPDATA%\CursorSwitcher\`
3. Run `Cursor Switcher.bat`

## Repository Contents

- `packs/` - all 280 cursor packs (.cur/.ani files)
- `apply-cursor.ps1` - PowerShell applier with auto role-detection
- `Cursor Switcher.bat` - main menu UI
